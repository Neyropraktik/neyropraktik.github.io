# Модуль 2. Формула промпта из 5 шагов

> Цель модуля: ставить задачу так, чтобы результат с первого раза был рабочим.
> Время: 4 урока + 2 задания + тест. ~50 минут.

---

## Урок 2.1. Промпт = заказ у бариста

Аналогия, которая объясняет всё: промпт для нейросети — как заказ у кофейни.

- «Кофе» → бариста убьют вопросами (какой? с чем? горячий?) — вы получите то, что он решит за вас.
- «Капучино на овсяном, средний, с собой» → моментально точный результат.

С нейросетью так же. «Напиши пост» — это «кофе». Модель выдаст серый текст «ни о чём»: без вашего контекста, без аудитории, без стиля.

Плохой промпт ≠ плохая модель. **90% плохих результатов — это плохая постановка задачи**, а не слабый ИИ.

Инверсия этой идеи работает и в обратную сторону: если результат ужасный — не меняйте модель, сначала перепишите промпт.

## Урок 2.2. 5 шагов идеального промпта

### Шаг 1. Контекст — что происходит?
Что за ситуация, какие данные, какая задача стоит. Без контекста модель достаёт «средний по интернету» ответ.

> «Малый бизнес по ремонту квартир в Казани, 3 мастера, средний чек 80 тыс. ₽…»

### Шаг 2. Целевая аудитория — кто читает?
Один и тот же текст для CEO и для новичка — два разных текста.

> «…аудитория: владельцы квартир 30–45 лет, впервые делают ремонт.»

### Шаг 3. Tone of Voice — как должен звучать?
Дружелюбно / экспертно / сухо / с юмором. Или дайте образец: «стиль как у этого текста: (вставка)».

> «…дружелюбно, без канцелярита, с конкретикой.»

### Шаг 4. Формат ответа — в каком виде?
Список, таблица, 3 пункта, письмо, 500 знаков. Без этого получите простыню.

> «…3 пункта по 2–3 предложения, в конце один призыв к действию.»

### Шаг 5. Ограничения — чего не должно быть?
Что запрещено: воды, эмодзи, клише «в мире цифровых технологий», выдуманных фактов.

> «…без общих фраз, без эмодзи, цифры только реальные.»

### Итоговый шаблон

```
Контекст: [ситуация, данные]
Аудитория: [кто читает]
Тон: [стиль]
Формат: [структура и объём]
Ограничения: [чего не должно быть]
Задача: [сама просьба]
```

Разница видна сразу:

- ❌ «Напиши пост про ремонт квартир»
- ✅ Полный шаблон выше → текст, который можно публиковать после правки.

## Урок 2.3. Роль, референс, обратная связь

Три приёма, поднимающие точность на уровень выше.

### 1. Задать роль
«Ты — маркетолог с 10-летним опытом в услугах для дома…» Роль задаёт словарный запас, глубину и типичные ошибки, которых модель будет избегать. Работает не всегда, но почти никогда не вредит.

### 2. Дать референс
Покажите образец: «Вот пост, который залетел: (вставка). Сделай по этой же структуре, но про другую тему». Референс сильнее любого описания стиля — модель копирует структуру точнее, чем следует инструкциям.

### 3. Обратная связь (итерации)
Не переписывайте промпт с нуля — правьте результат:
- «Слишком официально, сделай на 30% проще»
- «Второй пункт убери, третий раздвинь на два»
- «Добавь конкретику по срокам»

2–3 итерации почти всегда дают лучший результат, чем один «идеальный» промпт.

### Миф: чаевые нейросети
Расхожее мнение «напиши в конце "спасибо" — будет ответ лучше» — не подтверждено. Вежливость не влияет на качество. Влияют инструкция, данные и итерации.

## Урок 2.4. Факт-чек и анти-галлюцинации

Практика работы с фактами из модуля 1, теперь — инструментами промпт-инжиниринга.

**Приём 1. Попросите отделить факты от мнений:**
> «В конце ответа выдели раздел "Проверить": список утверждений, которые нужно проверить в первоисточнике.»

**Приём 2. Запретите выдумывать:**
> «Если не уверен в цифре — напиши "нет данных", не придумывай.»

**Приём 3. Явный факт-чек:**
> «Теперь проверь свой ответ: найди 3 самых слабых утверждения и объясни, почему они могут быть неверны.»

**Приём 4. Данные в, данные out:**
Для задач с цифрами — вставляйте исходные данные прямо в промпт и запрещайте выходить за их рамки.

Правило: **чем ответственнее результат (договор, цена, медицина, юрлицо), тем короче должен быть путь «проверка → публикация».**

## Задания 2

**2A (быстрое):** возьмите 3 своих реальных промпта, которые давали плохой результат, и перепишите по шаблону 5 шагов. Сохраните старую и новую версию рядом — разница и есть ваш прогресс.

**2B (проектное):** соберите один **универсальный рабочий шаблон** под свою основную задачу (пост / письмо / вакансия / отчёт) — с пустыми полями, которые вы заполняете за 2 минуты. Этот шаблон вы будете использовать каждый день.

**Критерий готовности 2B:** шаблон помещается на экран телефона и содержит все 5 шагов.

## Тест 2 (ответы в конце)

1. Главная причина плохого ответа нейросети — это:
   - а) слабая модель; б) плохая постановка задачи; в) плохой интернет.
2. Какой из 5 шагов отвечает за «список из 3 пунктов, по 2 предложения»?
   - а) контекст; б) тон; в) формат.
3. Что сильнее влияет на стиль ответа?
   - а) Описание «пиши красиво»; б) референс-образец; в) просьба вежливо.
4. Как бороться с выдуманными цифрами?
   - а) Запретить их: «если не уверен — нет данных»; б) переспросить; в) не использовать цифры вовсе.
5. «Напиши в конце спасибо — будет лучше» — это:
   - а) работающий приём; б) миф; в) часть формулы 5 шагов.

**Ответы:** 1-б, 2-в, 3-б, 4-а, 5-б.
