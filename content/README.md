# Курс «НейроПрактик 2026: от промпта до автоматизации»

Текстовый курс без вебинаров: уроки + задания + тесты. Материал на основе гайда и пакетов промптов проекта.

## Структура курса

```
course/
├── README.md              ← этот файл (запуск, цены, платформы)
├── program.md             ← полная программа: модули, уроки, задания, тесты
└── modules/
    ├── modul-1-baza.md       Модуль 1. База: как работают нейросети
    ├── modul-2-prompt.md     Модуль 2. Формула промпта из 5 шагов
    ├── modul-3-professii.md  Модуль 3. Промпты под профессии
    ├── modul-4-avtomatizaciya.md  Модуль 4. Автоматизация
    └── modul-5-monetizaciya.md    Модуль 5. Монетизация
```

## Формат

- **Урок** — текст 1 500–2 500 знаков, структура: теория → пример → разбор.
- **Задание** — тип A (быстрое: «напиши промпт, пришли результат») + тип B (проектное: «собери файл/план»).
- **Тест** — 5 вопросов с ответами в конце урока (самопроверка).
- **Финальный проект** — воронка целиком, в конце модуля 5.

Итого: **5 модулей, 17 уроков, 9 заданий, 5 тестов, 1 финальный проект.**
