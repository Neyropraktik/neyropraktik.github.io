# Бренд «НейроПрактик» — единый стиль

Логотип и обложка канала: неон-маджента на тёмном фиолетово-чёрном фоне.
Ниже — точные коды, чтобы любое новое оформление выходило «в цвет».

## Палитра

| Роль | Светлая тема | Тёмная тема |
|---|---|---|
| Акцент основной (маджента) | `#d331e8` | `#e44dff` |
| Акцент глубокий (текст, ссылки) | `#a41fc4` | `#d98cff` |
| Акцент светлый (glow) | `#f07dff` | `#f7a3ff` |
| Второй акцент (на neon-циан) | `#3ddbe8` | `#3ddbe8` |
| Фон | `#f6f4ef` (бумага) | `#0d0916` (базальт) |
| Карточка | `#fffdf9` | `#1b1428` |
| Текст | `#17130f` | `#f2ecfb` |

Градиент кнопок и логотипа: `#ff2bd6 → #7c3aed` (как в надписи «Практик»).

## Теглайн

```
ИИ • Идеи • Практика • Результат
```

Используется: в шапке лендинга, футерах, приветствии бота, описании канала и закрепе.

## Файлы, которые нужно положить сюда

| Файл | Откуда | Куда идёт |
|---|---|---|
| `banner.jpg` | баннер канала (1280×480) | соцпревью сайта (og:image), обложки постов (`publish.py --photo`) |
| `avatar.png` | аватар (квадрат ≥512×512) | аватар канала (`setup_channel.py --avatar`) |
| `boosty-cover.png` | обложка Boosty (1920×480, безопасные зоны под кроп) | страница Boosty (`content/boosty-page.md`) |
| `boosty-avatar.png` | аватар Boosty (620×620, логотип из Telegram-канала) | страница Boosty |
| `bundle-course.png` | обложка бандла «Курс НейроПрактик 2026» (1280×720) | бандл на Boosty |

Положи файлы с именами выше — дальше всё цепляется автоматически:
- `index.html` уже ссылается на `banner.jpg` в `og:image`;
- `scripts/setup_channel.py --avatar assets/brand/avatar.png` ставит аватар каналу через Bot API.

## Правила оформления

1. Тёмные фоны — только `#0d0916`…`#1b1428`, никаких чистых чёрных.
2. Свечения — маджента (`211, 49, 232` / `228, 77, 255` в rgba), не синие.
3. Второй цвет — циан `#3ddbe8`, не жёлтый.
4. Родительский градиент акцентов — `#ff2bd6 → #7c3aed`.
