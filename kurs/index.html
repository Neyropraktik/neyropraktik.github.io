Финальный проект

«Моя ИИ-воронка за 7 дней» — проверяется вручную (премиум-уровень) по чек-листу:

  1. Есть лид-магнит с понятной ценностью.
  2. 5 прогрев-постов с логикой (ценность → кейс → продажа).
  3. Карточка продукта по формуле: результат + срок + возражение.
  4. План публикаций на неделю с датами.
  5. Все промпты написаны по формуле 5 шагов.

Как проходить (инструкция для ученика)

  1. Читаешь урок → делаешь задание → проверяешь себя тестом.
  2. Тест сдаётся на 5/5 (или перечитываешь урок).
  3. Задания типа B складываешь в папку — это портфолио и основа финального проекта.
  4. Премиум: присылаешь задания автору, ответ в течение 48 часов.
Платформа

Быстрый запуск — Boosty + Telegram-бот (комиссия ~10%). Масштаб с автодоступом и тестами — GetCourse. Международная аудитория — Gumroad. При 50+ продажах рекомендуется переезд на GetCourse.
